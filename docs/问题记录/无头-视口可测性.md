# 问题：无头 `-b` 模式下能不能测视口相关的功能

**TL;DR**：能。Blender 5.2 的 `-b` 下**仍有 window / screen**，只有 OpenGL 渲染不行。

- **问题**：一开始以为「无头下没有视口，`space.shading`、`region_3d` 这些测不了」，
  于是把「实时预览」的核心断言写成了「预览模式下 `_viewport_spaces()` 返回空」
- **根因**：假设错了。实测 Blender 5.2 的 `-b` 下：
  - `bpy.context.window` 非空
  - `bpy.data.screens['Layout'].areas[...]` 拿得到真实区域
  - `bpy.context.window_manager.windows` 非空
  - `_viewport_spaces()` 返回 **1 个真实视口**
- **解决**：把测试改成**真测视口同步**（读真实 `space.shading` 与 `region_3d.view_perspective`），
  断言立刻从「自欺欺人」变成「真验证」
- **预防**：Blender 无头下**能测**的：`space.shading.*` 读写往返、`region_3d.view_perspective`、
  属性是否存在、图标枚举、Operator 注册与卸载。

  **不能测**的只有两类：
  - **任何 OpenGL 渲染** —— `bpy.ops.render.opengl()` 必报
    `RuntimeError: Cannot use OpenGL render in background mode (no opengl context)`
  - **面板 draw 的真实排版** —— 画不出界面

  想验「按钮会不会灰」用 `bpy.ops.xxx.poll()`，它不依赖 GL 上下文
