# 问题：无头测试断言浮点属性永远失败

**TL;DR**：RNA 的 `FLOAT` 是 C 32 位 float，断言里写 `0.4` 会得到 `0.4000000059604645`。

- **问题**：无头测试里 `shading.cavity_ridge_factor = 0.4` 之后断言它等于 `0.4`，稳定失败
- **根因**：`bpy` 的 `FLOAT` 属性底层是 C `float`（32 位），不是 Python 的 64 位 `float`。
  十进制小数大多无法被 32 位二进制精确表示
- **解决**：断言值用**二进制可精确表示**的数，或两边都 `round(x, 4)`

```python
# ✗ 必失败
check("ridge", shading.cavity_ridge_factor, 0.4)      # 实际 0.4000000059604645

# ✓ 可精确表示
shading.cavity_ridge_factor = 0.25                    # 0.25 = 2^-2，精确
check("ridge", shading.cavity_ridge_factor, 0.25)

# ✓ 或者两边都 round
check("ridge", round(shading.cavity_ridge_factor, 4), 0.3)
```

  **可精确表示**的常用值：`0.25 / 0.5 / 0.75 / 1.5 / 1.75 / 2.0`

- **预防**：跑无头断言前先想一下「这个十进制小数能被 32 位二进制精确表示吗」。
  另外这是**通用坑**，任何通过 RNA 读写的 float 都会遇到

## 旁证

`View3DShading.single_color` 的默认值读出来是 `0.800000011920929` —— 同一个原因，
它也是 32 位 float。顺带记住：`single_color` 是 **3 分量**（不是 RGBA 4 个）。
