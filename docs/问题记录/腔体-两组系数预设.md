# 问题：换了 cavity 类型，预设值就跳回旧数字

**TL;DR**：腔体有「世界」和「屏幕」两组系数，预设只写了当前那一组，另一组还是旧值。

- **问题**：用户从「世界」切到「屏幕」时，面板上显示的脊 / 谷还是旧值，不是刚套的预设值
- **根因**：腔体不是一套参数，而是**两组并存** ——
  - 世界：`cavity_ridge_factor` / `cavity_valley_factor`
  - 屏幕：`curvature_ridge_factor` / `curvature_valley_factor`

  `cavity_type` 决定哪一组参与渲染。预设只写了其中一组
- **解决**：`_apply_cavity_preset()` **一次写两组**，并顺带打开 `show_cavity`

```python
def _apply_cavity_preset(scene):
    """把腔体脊/谷系数写成预设值。世界与屏幕两组一起写 —— 面板随时可切类型。"""
    shading = scene.display.shading
    settings = scene.wqr
    ridge = float(settings.cavity_preset_ridge)
    valley = float(settings.cavity_preset_valley)
    if hasattr(shading, "show_cavity"):
        shading.show_cavity = True
    for attr in ("cavity_ridge_factor", "curvature_ridge_factor"):
        if hasattr(shading, attr):
            setattr(shading, attr, ridge)
    for attr in ("cavity_valley_factor", "curvature_valley_factor"):
        if hasattr(shading, attr):
            setattr(shading, attr, valley)
    return ridge, valley
```

- **预防**：凡是「成对 / 多组并存、用户可能切换」的参数，预设**一次全写**，
  别只写当前生效的那一组

## 顺带纠正的认知

Blender 5.2 里腔体相关**默认值都是 1.0**（不是 0.3），`show_cavity` 默认**关**，
`cavity_type` 默认 `SCREEN`。用户看到的 0.3 是**某个工程文件里存的值**。

- `cavity_type` ∈ `WORLD` / `SCREEN` / `BOTH`
- `cavity_*_factor`：hard 0–250、soft 0–2.5
- `curvature_*_factor`：0–2.0
- `cavity_type = WORLD` 时，`curvature_*_factor` **不会**被清零
