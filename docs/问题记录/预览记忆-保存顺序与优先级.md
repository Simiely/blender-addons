# 问题：关掉预览再打开，调好的外观又被重置了

**TL;DR**：关预览把外观还原了，下次开预览又走 0.3 出厂预设 —— 用户调好的样子两次都被冲掉。

- **问题**：用户在预览期间把光照 / 颜色 / 腔体调成满意的样子，关掉预览（要回 Cycles 干活），
  再打开预览时看到的又是出厂预设 0.3，**之前的调整全没了**
- **根因**：两个行为叠加
  1. `_stop_preview` 会把 `scene.display.shading` 还原到打开之前 —— **不保留**用户调好的值
  2. `_start_preview` 每次无条件套用 0.3 预设 —— 从不去看「上次是什么样」

  单看每条都合理（「关掉还原」本来就是用户要的），合起来就成了「调了也白调」
- **解决**：加一层**预览外观记忆**，把用户调好的样子存在 `Scene` 上，下次优先还原它

```python
def _save_profile(scene):
    """必须在还原之前调用，否则存到的是还原后的值。"""
    settings = scene.wqr
    if not settings.remember_preview:
        return False
    settings.preview_profile = _dump_profile(scene)   # JSON 字符串（shading + display 两层）
    settings.preview_profile_time = time.strftime("%m-%d %H:%M")
    return True

def _start_preview(scene, state):
    state["shading"] = _snapshot_shading(scene.display.shading)   # ① 先快照原值
    state["display"] = _snapshot_display(scene.display)           #    抗锯齿在 display 层
    state["spaces"] = _snapshot_viewports()
    profile = _load_profile(scene.wqr) if scene.wqr.remember_preview else None
    if profile:                                                   # ② 有记忆 → 用记忆
        _assign_attrs(scene.display.shading, profile.get("shading"))
        _assign_attrs(scene.display, profile.get("display"))
    elif scene.wqr.apply_cavity_preset:                            # ③ 没记忆 → 出厂预设
        _apply_cavity_preset(scene)
    ...

def _stop_preview(scene, state):
    if state.get("active"):        # ④ 只有真的在预览中才存
        _save_profile(scene)       #    ← 存完再还原，顺序不能反
    failed = list(_restore_viewports(state.get("spaces")))
    failed += _assign_attrs(scene.display.shading, state.get("shading"))
    failed += _assign_attrs(scene.display, state.get("display"))
    ...
```

- **预防**：三个要点，缺一个就出 bug

  1. **保存必须发生在还原之前** —— 否则存下来的是还原后的空值
  2. **记忆的优先级必须高于出厂预设** —— 否则用户调好的值每次开预览都被预设冲掉，等于白调。
     预设退化为「**首次使用 / 没有记忆时**」的兜底，面板标签也跟着改成「无记忆时套用预设」
  3. **闲置时不要写记忆** —— `_stop_preview` 用 `state.get("active")` 守卫；
     否则「预览没开时误触」「卸载插件时自动还原」都会把值写进记忆，污染下一次预览

## 配套要点

- **存储位置选 `Scene` 而不是插件 Preferences**：记忆随 `.blend` 保存，
  语义上是「这个工程的预览外观」，也与其他设置（输出目录、预设值）同处一地，不会跨工程互相污染
- **用 JSON 字符串存**：外观属性有 17 个（含字符串枚举、浮点数组），
  逐个建 `PropertyGroup` 字段既啰嗦又难同步；`json.dumps(...)` 一行搞定。
  v1.5.0 起还分了 `shading` / `display` 两层（抗锯齿不在 shading 上），
  见 [外观参数-分散在两个Struct上](./外观参数-分散在两个Struct上.md)
- **损坏要优雅回退**：`json.loads` 失败就返回 `None` 走预设分支，不能抛异常把面板打崩
- **写失败要报出来**：记忆里的 `studio_light` 可能指向已不存在的 `.exr`，
  复用 `_assign_attrs()` 收集失败名并在 Operator 里 report
