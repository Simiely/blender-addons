# 问题：取消实时预览后，枚举属性没还原、数值属性却还原了

**TL;DR**：快照时对字符串枚举做了 `tuple()`，还原时 `setattr` 抛 `TypeError` 又被 `except: pass` 吞掉。

- **问题**：关掉「实时预览」后，视口的光照 / 颜色等**枚举**属性停在预览状态，
  而数值 / 布尔属性正常回退
- **根因**：为了统一处理数组，快照代码对**所有**属性都 `tuple(value)`。
  字符串也会被拆成字符元组（`'STUDIO'` → `('S','T','U','D','I','O')`），
  还原时 `setattr` 抛 `TypeError`，而这个异常被 `except: pass` 静默吞了
- **解决**：加类型判断，只有非 `str/bool/int/float` 才 `tuple()`

```python
value = getattr(shading, name)
if not isinstance(value, (str, bool, int, float)):
    try:
        value = tuple(value)      # 只有 bpy_prop_array 才转
    except TypeError:
        pass
```

  并新增 `_assign_attrs()` 收集写失败的属性名，由 Operator 报出去：

```python
def _assign_attrs(target, data):
    """返回写失败的属性名（不静默吞）"""
    failed = []
    for name, value in (data or {}).items():
        try:
            setattr(target, name, value)
        except Exception:
            failed.append(name)
    return failed
```

- **预防**：**还原类操作绝不静默吞失败**。这个 bug 就是因为错误被吃掉才没早发现 ——
  靠测试逐属性对比才挖出来
