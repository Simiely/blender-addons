# 问题：打开预览时套用预设，把用户的原始值永久覆盖了

**TL;DR**：套用预设写在了快照**之前**，于是「原值」存下来的其实是预设值。

- **问题**：想让「一开预览就自动把腔体系数设成预设值 0.3」，但关掉预览后，
  用户原来的腔体值（如 1.75 / 1.25）回不来了
- **根因**：`_start_preview` 里先套用预设、后做快照 ⇒ 快照存的是**预设值**，不是原值
- **解决**：**必须先快照、后套用**

```python
def _start_preview(scene, state):
    # 先快照「未套用预设」的原值，保证关掉开关能还原回去
    state["shading"] = _snapshot_shading(scene.display.shading)   # ① 先存原值
    state["spaces"]  = _snapshot_viewports()
    if scene.wqr.apply_cavity_preset:
        _apply_cavity_preset(scene)                               # ② 再覆盖
    _apply_preview_to_viewports(scene, scene.wqr.preview_camera)
    state["active"] = True
```

- **预防**：任何「临时改值 + 可还原」的功能，先问一句
  **「快照拿到的是原值还是新值」**。

## 配套设计：给用户一个「永久写入」的出口

因为「关开关会还原」，用户没法用开关把预设值留下。所以额外提供一个**独立按钮**
（`wqr.apply_cavity_preset`）——它明确**不走快照**，点它就是永久写进场景。

**还原语义要写清楚**：关预览 = 全还原（含自动套用的预设）；
渲染类按钮 = 只还原输出设置，不碰外观；「套用这个预设」= 什么都不还原。
